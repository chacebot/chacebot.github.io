# About

Personal webpage for Chace Medeiros

### Deployments

run `npm run deploy` to publish

### Pages Configuration

Branch: `gh-pages`
Directory: `/root`

### Video Background

The home page uses a video background. Place your video file (`denali-furling`) in the `public/` folder with one of these formats:
- `denali-furling.mp4` (recommended)
- `denali-furling.mov`
- `denali-furling.webm`

The video will automatically loop and play as the background on the home page.
